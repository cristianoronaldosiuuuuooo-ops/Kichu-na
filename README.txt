অপূর্ণ ইচ্ছে | Editable Post Maker

কী আছে:
- index.html = মূল Post Maker
- assets/background.png = তোমার দেওয়া background
- assets/fonts/ = bundled Bengali fonts
- manifest.json + sw.js = PWA/shortcut-ready files

ব্যবহার:
1. ZIP extract করো।
2. index.html browser-এ খুললে text paste করে preview দেখতে পারবে।
3. JPG হিসেবে Save চাপলে final image তৈরি হবে।
4. অন্য background দরকার হলে file picker থেকে ছবি দেওয়া যাবে।

Home-screen shortcut:
এই ZIP-টি PWA-ready। সরাসরি file:// থেকে Android browser সবসময় "Add to Home screen" দেয় না।
Shortcut/standalone app হিসেবে ব্যবহার করতে হলে folder-টি কোনো static web hosting-এ upload করে সেই HTTPS address Chrome-এ খুলে "Add to Home screen" / "Install app" ব্যবহার করো।
